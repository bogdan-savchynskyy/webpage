Unsupervised Deep Multi-Graph Matching and Cycle-Consistency for Atlas-to-Worm Annotation

Project Goal

The goal of this project is to automate the annotation of microscopic images of C. elegans worms using an established biological atlas. Because of natural variability and imaging conditions, this requires matching a set of target worm images simultaneously to the atlas and to each other.

Step 1: Unsupervised Deep Graph Matching

We represent the atlas and individual worms as graphs where nodes correspond to cells/nuclei and edges capture spatial relationships. We use deep neural networks to learn node and edge features directly from image data without explicit annotation labels, driven by custom geometric alignment losses.

Step 2: Cycle-Consistent Multi-Graph Matching

Matching multiple worms independently to the atlas often yields contradictory results. We enforce cycle-consistency—meaning the composition of matchings along any closed loop of graphs must map a node back to itself. This allows correct annotation sharing across the population of images.

Step 3: Scalable Combinatorial Optimization

Enforcing cycle-consistency over large scale imaging datasets leads to NP-hard optimization problems. We construct highly scalable mathematical programming algorithms based on Lagrangean decompositions and Max-Weight Independent Set formulations to handle hundreds of worm datasets efficiently.
